# Glossary

- **SKU** - stock keeping unit
- **Location / Bin** - physical place stock is held
- **Movement** - immutable ledger line changing stock at a location
- **Putaway** - moving received goods to storage locations
- **Allocation** - reserving stock for an order
- **Wave / Pick list** - batch of orders released for picking
- **LPN** - license plate number identifying a pallet/carton
